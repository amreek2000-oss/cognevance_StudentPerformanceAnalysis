# Student Performance Analysis - Level 1 Internship Project

## 📌 Project Overview
Exploratory Data Analysis (EDA) on 1,500 students to evaluate academic performance trends and analyze the correlation between attendance percentage and final grades.

* **Organization**: Cognevance Technologies
* **Domain**: Data Analytics
* **Level**: Level 1 (Easy)

---

## 🛠️ Tools & Technologies
* **Language**: Python
* **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, SciPy
* **Environment**: Google Colab / Jupyter Notebook
